# Hindsight

> **번역 안내.** 이 문서는 [README.md](./README.md)의 기계 번역 보조본이며 원어민의 검토를 거치지 않았습니다. 숫자와 주소는 영문 원본과 `deployments.json`이 기준입니다. 두 문서가 다르면 영문이 맞습니다.

**Attestcoin은 이미 루트를 증명합니다. Hindsight는 노드가 보관하기 전까지 그 루트가 사는 곳입니다.**

Attestcoin의 읽기 쿼리 하나는 이더리움 블록 트랜잭션 루트의 연속 구간을 검증합니다 — 반년 된 블록이면 수백 개 — 그리고 호출이 끝나면 버립니다. 검증은 기억이 아니기 때문입니다. Hindsight는 그것을 보관합니다. 한 번 보관된 높이에 대해서는, 같은 블록의 다른 어떤 트랜잭션도 `view` 호출 하나로 증명됩니다: 프루버 없이, `0x0FD2` 없이, 지갑 없이, 누군가 끌 수 있는 것 없이.

## 세 층

| 층 | 컨트랙트 | 하는 일 | 소유자 |
|---|---|---|---|
| L0 기억 | `EthereumMirror` | 프리컴파일이 검증한 연속 구간의 모든 루트를 보관합니다. 봉인된 스팬은 "이 구간에 빈 높이가 없다"를 한 번 증명하고 기록합니다. | 없음 |
| L1 파일 | `AbsenceRegistryV3` | 담보가 걸린 부정 진술("이 주소는 여기서 청산된 적 없다")과 완전성 진술("이것이 전부다"). 반박하면 담보의 절반은 반박자에게, 절반은 소각. 확정된 진술은 **경제적** 사실이지 증명이 아니며, 어디서나 그렇게 표시됩니다. | 없음 |
| L2 거절 | `UnderwritingDesk` | 아카이브와 파일을 읽고, 지급하거나 거절하며 이유를 이름으로 말합니다. 점수도, 발행도, 숫자도 없습니다. | 없음 |

그리고 그 위에: `SubjectBinding`(이더리움 주소가 자신을 대변할 Creditcoin 키에 서명), `Cover`(열려 있는 주장에 대한 보험, 헌트가 결제). 모두 소유자 없음, 일시정지 없음, 업그레이드 없음.

## 지금 숫자

모든 수치는 `worker/src/measure.ts`가 체인에서 읽어 `deployments.json`에 기록한 값이며, [CLAIMS.md](./CLAIMS.md)가 증거와 함께 등급화합니다. 최신 값은 [hindsight.run/record](https://hindsight.run/record/)와 [hindsight.run/status](https://hindsight.run/status/)에 있습니다.

- 메인넷 높이 79만 개 이상 보관, 상단 구간은 약 110일 동안 빈 곳 없음. 그 아래의 구멍은 호스팅 프루버를 끈 채 `0x0FD3` 체크포인트와 공개 영수증만으로 수리 중입니다.
- 실제 프리컴파일과의 차분 검사 2,684건(위조 포함), 불일치 0건.
- 데스크 상품 8개: Aave V3, Morpho Blue, Compound V3, Spark, Circle USDC `Blacklisted`. 90일 검사는 Foundry에서 43,325 가스, Creditcoin에서 407,960 가스 — 대체된 데스크는 같은 질문에 7,041,373 가스를 썼습니다(둘 다 채굴된 영수증).
- 공개 게이트 22개가 저장소의 약속을 실시간 상태에 대해 재실행합니다. 하나라도 실패하면 `/api/gates`는 503으로 답합니다.

## 아직 아닌 것

- **검증된 외부인 없음.** 두 소비자 컨트랙트는 같은 사람의 것이고, 리더보드의 이름은 이 프로젝트의 헌터이며, 데스크가 지급한 유일한 차입자는 이 프로젝트의 지갑입니다. 사이트는 이것이 중요한 모든 곳에서 그렇게 말합니다.
- **180일이 아니라 약 110일.** 심층 백필은 프루버 없이 동작하며 시간과 가스가 듭니다. 실측 속도로 며칠이 걸리고, `/status`의 `run-unbroken` 게이트가 보여주기 전까지는 주장하지 않습니다.
- **아무도 이더리움 주소를 바인딩하지 않았습니다.** 컨트랙트는 배포되고 바이트코드가 검증되지만, 태그가 담긴 이더리움 트랜잭션에는 자금이 있는 이더리움 지갑이 필요하며 이 프로젝트에는 없습니다.

## 직접 확인하기

```bash
git clone --recurse-submodules https://github.com/iamdflame/HINDSIGHT && cd HINDSIGHT
(cd contracts && forge test)                       # 프리컴파일을 삭제하는 테스트 포함
npx hindsight-mirror verify 0x3a4b8bcf…            # 키 없이, 가스 없이: view 호출
npx hindsight-mirror mandate assess 0x7562be20…    # 데스크의 판정, 모든 상품
npx -y hindsight-run-mcp                                # 에이전트용 MCP 서버, 자금을 쓸 수 없음
```

제품 얼굴은 [mandate.hindsight.run](https://mandate.hindsight.run)입니다. 같은 종이, 같은 밀랍, 같은 런타임. 그 화면에는 *프리컴파일*이라는 단어가 없습니다.

아무것도 발행되지 않고, 아무것도 양도되지 않으며, 숫자는 없습니다.
